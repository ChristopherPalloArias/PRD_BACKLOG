## Convenciones
 
| Campo | Descripción |
|---|---|
| **ID** | Identificador único del caso: `TC-XXX` |
| **CA asociado** | Criterio de aceptación de la historia de usuario que cubre este caso |
| **Prioridad** | Crítico / Alto / Medio / Bajo — según sección 12.1 del TEST_PLAN |
| **Estado** | Sin ejecutar / Pasó / Falló / Bloqueado |
| **Resultado obtenido** | Se completa únicamente al ejecutar el caso; en entregable documental se registra como "Sin ejecutar" |
